# UserAgent

このライブラリは、ユーザーのデバイスがiOSデバイス（iPhone、iPad、またはiPod）であるかを検出します。

## 使い方

```js
import { isIOS } from "https://code4fukui.github.io/UserAgent/isIOS.js";

console.log(isIOS());
```

## 機能

- ユーザーがiOSデバイス（iPhone、iPad、またはiPod）を使用しているかを検出
